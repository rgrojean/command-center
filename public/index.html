WALKTHROUGH

How a run works

  1. Point at a spec pair. Defaults are a bundled v2/v3 OpenAPI sample and fleet.json. Swap either file to try your own APIs.
  2. Check LIVE to kick off a live Cursor SDK call, spinning up agents per repo. Leave it off for a fast stub rehearsal (canned fixtures, no API key calls).
  3. NEXT opens the swimlane. Before RUN, add optional business context — domain notes injected into LEGOLAS (research) and GIMLI (write).
  4. Research fans out per repo. You approve or reject at the gate. Approved write agents open a PR artifact (this demo does not push to your GitHub unless configured).

Download the sample fleet.json if you want a template for your own repos. Specs stay OpenAPI — nothing here is locked to one industry.

BEFORE YOU RUN

Add business context

Optional. Write how this API is used in the business — compliance, naming, what must not be shimmed. The same text is copied into every LEGOLAS and GIMLI prompt.
